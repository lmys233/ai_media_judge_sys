# AI Judge System 启动命令

## AI 自动审核引擎（文本 + 图片）
```bash
.\.venv\Scripts\python -m src.app --worker ai-auto --llm-provider qwen --llm-api-key <your-api-key>
```

支持两种媒体类型的自动审核：
- **text**: NB快速打标→文本重写→向量检索→LLM判断→结果回传
- **image**: CLIP快速打标→VL描述生成→向量检索→VL判断→结果回传

## 人工案例同步（同步到 NB 训练语料 + Milvus 向量库）
```bash
.\.venv\Scripts\python -m src.app --worker manual_case
```

## 其他 Worker

| Worker | 用途 |
|--------|------|
| `ai-auto` | AI自动审核（文本+图片）：NB/CLIP快速打标→重写→向量检索→LLM/VL判断→结果回传 |
| `manual_case` | 消费人工审核结果，同步到NB训练语料和Milvus向量库 |
| `task` | 完整审核引擎（需要torch/cv2，支持媒体解析） |
| `manual_result` | 消费人工复核回传结果 |
