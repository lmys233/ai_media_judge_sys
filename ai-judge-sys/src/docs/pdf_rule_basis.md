# PDF 规则依据（AEGIS2.0 -> 中文审核）

本文档说明如何将 `media/2501.09004v1.pdf` 作为规则基线使用。

## 提取结果

根据 PDF 的 Table 2，可得到以下分类体系：

- 12 个核心风险类别
- 9 个细粒度风险类别
- 三级判定标签：`safe`、`needs_caution`、`unsafe`

提取并本地化后的规则文件位于：

- `src/policy/aegis2_zh_taxonomy.yaml`

## 朴素贝叶斯是否需要这些规则？

简答：**需要用于标签设计，但不能直接作为训练语料**。

- 朴素贝叶斯需要带标签的中文样本来学习词分布。
- taxonomy 的作用是定义类别目标与策略边界。
- 因此 taxonomy 是“分类框架”，训练数据仍需中文且贴合业务场景。

## 为什么英文 PDF 对中文场景仍有价值

1. 提供完整、稳定的风险本体结构。
2. 支持多标签与 `needs_caution` 中间态判定。
3. 避免漏掉高风险类（如自残、未成年人性内容、欺诈）。
4. 可在保持类别 ID 稳定的前提下做中文本地化，便于工程一致性。

## 中文部署建议

1. 保持 taxonomy 的 ID 稳定（YAML 中可保留英文 ID）。
2. 为每个类别扩展中文关键词、短语与语义表达。
3. 补充中文社媒常见黑话、谐音、缩写词表。
4. 结合人工审核持续回流，迭代纠错与更新规则。
